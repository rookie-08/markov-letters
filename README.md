# markov-letters

A Python module that uses a Markov chain, after analyzing a text
file, to predict the next letter and generate fake words.

**Inspiration**
- [M J, Ashwin. "Next Word Prediction using Markov Model."](https://medium.com/ymedialabs-innovation/next-word-prediction-using-markov-model-570fc0475f96)
- [Veritasium. "The Strange Math that Predicts (Almost) Anything."](https://www.youtube.com/watch?v=KZeIEiBrT_w)

**Disclosures**
- I asked ChatGPT to generate datasets of words, with the
exception of `words.txt`, `words_simple.txt`, and `lorem_ipsum.txt`.
Data may be incorrect.
- `words.txt` is a collection of at least 466k words, which may
contain offensive words or slurs. Please read at your own discretion.
